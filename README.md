# Genómica en Rosa

Guía de estudio interactiva para el primer parcial de **Genómica y Proteómica** (parte de genómica).

Armada a partir de: Actividad previa, Clase 1, Clase 2, Clase 3, TP 1 y TP 2.
Las preguntas salen de los parciales 2023, 2024, recuperatorio 2024, 2025 2C y 2026 1C,
y de los finales 2022, junio 2023, diciembre 2024 y julio 2025.

## Contenido

- **Resúmenes** — 7 unidades (genoma humano, ómicas y validación, HGP + NGS, variación y bases de datos, TP1, TP2, cfDNA prenatal).
- **Tarjetas** — ~90 flashcards con progreso guardado por navegador.
- **Preguntas** — banco de V/F y multiple choice con explicación, más 13 preguntas de desarrollo con criterios de corrección.
- **Simulacro** — examen cronometrado (45 min) armado al azar del banco.
- **Recursos** — mapa de archivos, tabla de tecnologías, patrones de herencia en el VCF, criterios ACMG, errores frecuentes y glosario buscable.

## Archivos

- `page.html` — el contenido de la página (formato Artifact: sin `<html>`/`<head>`/`<body>`).
- `index.html` — la misma página envuelta en un documento HTML completo, para abrir localmente o servir con GitHub Pages.

Para regenerar `index.html` después de editar `page.html`, envolvé el contenido con el
esqueleto `<!doctype html> … <head> (charset + viewport) … <body>`.
